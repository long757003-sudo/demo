# 阶段五专家评审管理设计方案（2026-03-27）

**文件性质**：Demo 前端技术施工文档，描述专家管理和评审管理模块的具体实现方案。
**状态**：草案，方法一（严格计划遵循）。

## 知识摘要

### 专家数据字段规范（7 个核心字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 唯一标识 |
| `name` | string | 姓名 |
| `title` | string | 职称 |
| `dept` | string | 所在院系/机构 |
| `category` | string | 类别：技术 / 业务 / 用户 |
| `isExternal` | boolean | 是否校外专家 |
| `phone` | string | 联系方式 |
| `status` | string | 正常 / 黑名单 |

**黑名单独立存储**：黑名单记录（原因、时间、是否可申请移除）存储于独立的 `blacklist` 数组，不混入 `experts` 数组。

### 评审视图清单（7 个视图）

| 视图 ID | 说明 |
|---------|------|
| `expert-list` | 专家库（含统计信息：校内/校外数量） |
| `expert-blacklist` | 黑名单专家列表 |
| `expert-invitations` | 专家邀请记录（含 BR-05 比例验证） |
| `review-list` | 评审记录列表（论证+验收，Tab 切换） |
| `review-launch` | 发起评审（含 BR-05 实时校验） |
| `review-opinion` | 填写评审意见（五维打分 + 结论） |
| `my-reviews` | 我的评审任务（专家角色待办） |

### BR-05 校外专家比例验证逻辑

```javascript
const externalCount = selectedExperts.filter(e => e.isExternal).length;
const totalCount = selectedExperts.length;
const ratioOk = totalCount >= 3 && externalCount / totalCount >= 1/3;
```
比例不足 1/3 时阻止提交，显示提示。黑名单专家在选择界面自动 disabled。
