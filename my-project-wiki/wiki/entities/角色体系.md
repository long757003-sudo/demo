# 角色体系

[[全生命周期管理系统]] 共定义 **12 类角色**（按 UI 权限视角，Demo 设计规格 2026-03-26 版本，含 260323 会议新增的[[协助人角色]]）：

> **视角说明**：本页按 **UI 权限粒度** 列出 12 类角色。[[业务流程说明书V1.1]] 按**业务流程参与者**粒度列出 9 类角色（合并系统管理员/信息办专员、省略协助人/财务管理员/领导小组办公室等 UI 专属角色）。两者非矛盾，按需选用：产品 / Demo 开发参考 12 类，业务流程建模参考 9 类。

| 角色                      | 对应机构       | 核心权限                               |
| ----------------------- | ---------- | ---------------------------------- |
| 系统管理员                   | [[信息办]]    | 全局配置、角色管理、流程引擎维护                   |
| 信息办管理员（信息办专员）           | [[信息办]]    | 需求征集发布、初筛、组织论证、审核、验收组织、运维监管        |
| 信息办领导                   | [[信息办]]    | 审批、决策看板、报告导出                       |
| 领导小组成员（数智化建设领导小组）       | 数智化建设领导小组  | 重大项目审定、成效评估、全局看板                   |
| 领导小组办公室                 | 挂靠党政办与信息办  | 中/小/微型项目审定、进度监控                    |
| **用户单位系统管理员**（二级单位管理员）  | [[二级单位]]   | 指派需求填报权限、对本单位需求排序提交、分派协助人授权        |
| 用户单位项目负责人（二级单位经办人）      | [[二级单位]]   | 需求申报、项目实施管理、验收初验、运维管理              |
| 用户单位项目协助人（**260323新增**） | [[二级单位]]   | 权限与项目负责人相同，仅限立项申报书阶段，需领导审批方可添加     |
| 用户单位分管领导（二级单位负责人）       | [[二级单位]]   | 内部审批、签字确认；可对本单位需求进行优先级排序           |
| 合同管理员                   | 采购与招投标管理中心 | 合同台账管理、合同审定归档                      |
| 财务管理员（财务专员）             | 财务部        | 只读查看经费使用情况（合同进度款 + 年度预算总览），不直接操作付款 |
| 专家委员会（校内/校外专家）          | 外部/内部      | 参与论证、验收评审                          |

> **已确认（260323）**：协助人已正式纳入角色体系。
> **补充（demo-design 2026-03-26）**：用户单位系统管理员作为独立角色明确化（负责指派权限与排序）；合同管理员独立于财务管理员单列；财务管理员在 Demo 中为只读权限。系统角色表中的正式定义待业务方补充确认。

## 审批权限说明

- **重大项目**（>200万）→ 领导小组审定
- **中/小/微型项目** → 领导小组办公室审定
- **预算<5万** → 信息办审批后可直接立项
