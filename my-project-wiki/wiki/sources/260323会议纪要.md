# 2026-03-23 会议纪要

- **性质**：直言团队向学校展示近期工作成果和交互 demo，学校给出开发和修改建议

## 核心决策与要求

### 1. 登录入口

常用登录流程起点为**西南大学门户网站**（SSO 统一入口）。

### 2. 里程碑节点（已调整）

> **已确认**：以会议版本为准，[[全生命周期管理系统]] 全局流程已更新，新增"绩效评估"和"报废"节点。

新里程碑：**立项 → 招采 → 验收 → 运维 → 绩效评估 → 报废**

新增"绩效评估"和"报废"两个节点，产品方案中未覆盖。

### 3. 新增对接系统

在产品方案已有系统（身份认证/财务/资产/OA/邮件）基础上，新增：
- **招采系统**（新增）
- 财务系统（已有，本次再次强调）

### 4. 流程节点配置

发起需求征集/立项时，需要**配置业务流程节点信息**（可配置化流程）。

### 5. 需求征集流程细化（已调整）

> **已确认**：以会议版本为准，[[需求征集模块]] 流程已按此版本重新设计。

新流程：
```
信息办发送需求征集通知+公告
    → 二级单位系统管理员
    → 指派项目负责人
    → 系统管理员对需求进行排序
    → 二级单位领导审批
```

### 6. 协助人角色（新增）

立项申报书填写过程中/之前可添加**协助人**：
- 权限与项目负责人相同
- 需给相关领导进行审批

详见 [[协助人角色]]。

### 7. 专家评审细化（8项新要求）

详见 [[专家评审规则]]。

### 8. 立项通知

立项通知发送给**二级单位相关人及领导**（明确通知范围）。

### 9. 施工进度与付款

施工进度与合同进度款一致；若无支付时间节点，以**施工文件为准**。

### 10. 验收发起前置条件

发起验收时，需满足**必要文件均已上传**（系统校验）。
