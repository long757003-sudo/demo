# 技术架构

[[全生命周期管理系统]] 推荐技术栈：

| 层级 | 推荐方案 |
|------|---------|
| 前端 | Vue 3 + Element Plus / Ant Design Vue |
| 后端 | Spring Boot + MyBatis Plus / Java |
| 数据库 | MySQL 8.0 + Redis 缓存 |
| 工作流引擎 | Flowable / Activiti（支撑审批流、论证流、验收流） |
| 文件存储 | MinIO（校内部署） |
| 消息队列 | RabbitMQ（异步通知、定时任务） |
| 搜索引擎 | Elasticsearch（全局搜索、文档检索） |
| 部署 | Docker + K8s（校内私有云） |

## 关键设计点

- 工作流引擎（Flowable/Activiti）是核心组件，驱动审批流、论证流、验收流等所有流程节点
- 部署在校内私有云，数据不出校
- MinIO 负责所有项目文档的存储和归档

## 钉钉深度集成（已确认纳入）

来源：[[申报书技术规范]]。西南大学申报书明确要求所有信息系统须与**西南大学专属钉钉平台**深度集成，需纳入本系统技术方案：

| 集成点 | 要求 |
|-------|------|
| SSO 登录 | 支持通过钉钉账号单点登录 |
| 消息通知 | 审批节点、状态变更等通知推送至钉钉 |
| 微应用入口 | 系统以微应用形式嵌入钉钉工作台 |

> **已确认**：钉钉集成已纳入技术方案，对接规范待与学校信息办确认接口文档后补充。
