# 系统视图规范

[[全生命周期管理系统]] Demo 共定义 **40 个视图**，采用 **4 种页面模板**。本页记录系统 UI 结构约定，供后续开发参考。

## 整体布局

```
┌──────────────────────────────────────────────────────────┐
│  系统名称                            当前角色: [下拉▾] 退出  │  顶部导航
├──────────────┬───────────────────────────────────────────┤
│  左侧菜单    │  面包屑导航                                 │
│  （按角色    ├───────────────────────────────────────────┤
│   动态渲染） │                                            │
│              │           右侧内容区                        │
│              │                                            │
└──────────────┴───────────────────────────────────────────┘
```

角色切换通过顶部下拉框完成，切换后菜单和内容区实时刷新。

## 四种页面模板

### T1 · 仪表盘模板
用于**工作台首页**和**系统使用情况**。
- 统计卡片行（数量随角色变化）
- 待办事项区（超期项标红）
- 项目动态区
- 系统通知区（右侧三级：🔴 逾期预警 / 🟡 截止提醒 / 🔵 流程通知，含时间戳和来源，右上角显示未读角标）

### T2 · 列表模板
用于**所有管理列表页**。
- 搜索筛选栏（关键词 + 多下拉 + 查询 + 新建）
- 数据表格，分页每页 10 条
- 可排序列：预算金额、申报日期、截止日期（点击列头切换升/降序，当前列标蓝）
- 截止日期：临近 7 天标橙，超期标红

### T3 · 表单模板
用于**所有填报/申请页**。
- 表单标题
- 分组字段（两列栅格），必填字段标 `*`
- 预算金额字段自动识别项目类型（微型/小型/中型/重大）
- 底部：「暂存草稿」+「提交审核」

### T4 · 详情模板
用于**项目详情页**及**审批操作页**。
- 项目头部：名称 + 当前阶段标签 + 操作按钮（按角色和阶段动态）
- **生命周期进度条**：需求征集→立项论证→采购→实施→验收→运维，当前蓝/已完成绿/未开始灰
- 审批流时间轴（已完成/进行中/待处理）
- 详情内容区（基本信息 + 关联文档）
- **操作记录 Tab**（所有 T4 均有）：完整变更时间轴，每条含时间/操作人/操作类型/字段级 before-after 对比，只读不可删改
