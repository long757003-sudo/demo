# 西南大学信息化项目全生命周期管理系统

## 定位

面向[[信息办]]及各[[二级单位]]的信息化项目管理平台，以《西南大学信息化项目管理办法（试行）》为制度蓝本，将纸面制度转化为可执行、可监控、可追溯的数字化工作流。

## 全局流程（里程碑以 260323 会议版本为准）

```
需求征集 → 初筛遴选 → 立项申报 → 论证评审 → 立项审批 → 立项下达
    → 采购调研 → 采购执行 → 合同签订 → 项目实施 → 进度监控
    → 内部初验 → 正式验收 → 项目移交
    → 运维管理 → 绩效评估 → 报废
```

每一步均可触发**终止流程**。"绩效评估"和"报废"为 260323 会议新增里程碑节点，产品方案原版本未覆盖，需补充设计。
