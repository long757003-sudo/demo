# 监督与评估机制

来源：[[信息化项目管理办法]] 第十一章（第五十-五十一条）

## 机构分工

| 机构 | 职责 |
|------|------|
| 领导小组 | 根据需要对项目进行检查和评估 |
| 信息办 | 具体实施检查评估并汇报，为决策提供依据 |
| 审计处 | 依计划对项目相关内容进行审计，提出整改意见并督促整改 |
| 师生 | 可对违规行为进行监督举报，**举报属实给予奖励**，并追究违规者责任 |

## 评估维度（第五十一条）

项目进度、质量、成本、**效益**、用户满意度

## 评估方法

文档审查、实地考察、数据分析、问卷调查
