# 验收内容规范

来源：[[验收阶段实施细则]] 第五章第二节（第二十四-二十七条）

## 六大验收维度

### 1. 文档完备性和符合性（第二十四条）

验收文档符合《重庆市市级政务信息化项目管理办法》及配套标准规范要求；内容符合信息化项目实施管理要求。

### 2. 流程合规性（第二十五条）

项目审批、建设、管理流程符合相关管理规范。

### 3. 建设内容一致性和适用性（第二十六条）

| 子项 | 验收内容 |
|------|---------|
| 硬件设备 | 名称/型号/品牌/参数/数量与合同一致，加电试运行正常 |
| 系统功能性能 | 功能完成情况、并发量/响应时间等非功能性指标 |
| 安全防护 | 等保定级、密码应用、网络安全防护（依据《网络安全法》《密码法》） |
| 数据资源共享开放 | 数据总体设计、系统关联性、数据共享、数据标准、数据质量（依据《数据资源共享开放审查报告》）|
| 网络建设 | 网络架构、选型、拓扑结构、带宽、配置 |
| 建设效果评估 | 建设目标完成度、社会效益和经济效益 |

### 4. 质保运维服务评估（第二十七条）

评估质保运维服务内容、措施、期限，以及运维方案的可执行性。

## 初步验收前提条件（第八条）

1. 按合同完成建设内容，符合建设目标
2. 重大问题已解决，无未决纠纷
3. 第三方软件持有合法授权使用证书
4. 硬件设备加电试运行正常
5. 非涉密软件已完成**数据资源开放共享自查**
6. 如有变更，变更流程合规

## 竣工验收前提（第十六条）

1. 通过试运行并完成整改
2. **通过第三方信息安全等保测评**（按国家标准或行业标准）
3. 含软件开发项目：提供第三方软件测评报告
