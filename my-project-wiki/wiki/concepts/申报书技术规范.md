# 申报书技术规范

来源：[[表单模板汇总]] 中申报书填写说明的应用系统开发与数据规范部分。适用于所有信息系统类项目。

## 系统集成适配要求

申报书要求所有信息系统须与西南大学专属钉钉平台深度集成，详见 [[钉钉集成规范]]（SSO、消息通知、微应用及待确认接口事项）。

## 交付文档规范

供应商在系统验收前必须提供：
1. 系统主线业务的**业务流程图**
2. 系统涵盖的**主要业务模块列表**
3. 每个模块的**主要功能和具体功能点描述**

## 用户体验标准

- 全面兼容 HTML5，支持移动端响应式布局
- 多终端自适配，无需安装插件
- 支持主流浏览器：Chrome、Safari、Edge、Firefox、Opera 等

## 系统运维接管规范

验收前必须将以下内容移交信息化建设办公室：
- **数据库及系统超级管理员账号和口令**
- 数据字典
- SDK 及各类接口（APIs/SPIs、WebService、微服务等）详细调用说明
- 系统运维管理操作指南

## 数据接口规范

接口信息须包含：身份、权限、数据、资源、服务、业务等。

数据字典须包含：数据表服务的业务功能、数据项的数据类型/长度/中文含义/与外部表关联性描述。

## 数据统计分析功能

系统必须具备多维统计分析，至少包括：
- 系统重要日志
- 业务关键指标
- 支持数据导出、报表生成和 API 接口

## 数据治理要求

全校性、领域性业务系统主管部门须对重要业务数据进行**编目**：

| 编目字段 | 内容 |
|---------|------|
| 数据项编号、分类 | — |
| 责任科室 | — |
| 格式、属性 | — |
| 更新频率 | — |
| 共享类型、共享方式 | — |
| 使用要求 | — |

编目经信息办审核后，业务系统须按目录结构实现与**学校数据中台的共享**。
