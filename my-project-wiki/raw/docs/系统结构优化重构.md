日期：2026年4月20日

### 背景

为了更加契合全生命周期管理理念，现在需要对整体菜单结构及主要功能菜单进行规划升级。主要解决功能菜单分散，没有一个单独的功能区能完整的追溯整个项目的信息，包括从需求创建到验收上线进入运维阶段，再到项目终止下线。需要设计一个功能模块来承载诉求。

### 方案设计建议

- 加一个顶级菜单「项目全景」+生命周期视图页（不动现有菜单）
- 核心页：项目生命周期视图——以单个项目为主语，按阶段横向铺开整条链： 需求征集 → 立项论证 → 合同采购 → 实施/变更  → 验收上线 → 运维日志 → 终止下线
- 每个阶段一个可折叠的时间块，里头就是指向现有详情页的入口（不重写数据，只聚合 ），附阶段状态徽章（进行中/已完成/风险）。
