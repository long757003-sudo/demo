# 立项论证模块

[[全生命周期管理系统]] 第二步。权威版本：[[业务流程说明书V1.1]]（BPD-2026-002）。

## 模块概述

需求入库后，项目负责人从需求库发起立项，编制申报书并完成供应商调研；信办管理员审核后组织专家论证；领导小组审定通过后下达《立项通知书》，触发 [[项目招采模块]]。

## 主流程（10 步）

1. 项目负责人从需求库选择需求，发起立项
2. 填报《申报书》（建设目标、技术方案、采购清单、甘特图等）
3. **子流程 B**：供应商调研（非单一来源采购须调研 ≥ 3 家）
4. 提交申报材料 → 状态「申报材料审核中」
5. 信办管理员审核（不合规退回修改）
6. **子流程 C**：组织专家论证会 → 状态「专家论证中」
7. 论证结论（通过 / 修改后通过 → **子流程 D** / 不通过 → **子流程 E**）
8. 汇总拟建项目清单
9. 审定：重大项目由领导小组、中/小/微型由领导小组办公室
10. 下达《立项通知书》 → 状态「已立项」 → 触发 [[项目招采模块]]

## 子流程

### B：供应商调研
- 选择 ≥ 3 家供应商 → 系统生成《供应商调研情况对比报告》
- 附于申报材料一并提交

### C：专家论证会组织
- 论证方式（线上/线下）；线下需填会议地点
- 专家规格详见 [[专家评审规则]]
- 发出邀请（优先响应模式）→ 信办领导审批名单
- 阶段内专家阅读评审须知、提问、项目负责人答疑
- 8 维度 1-5 分打分 + 文字意见 + 手写签名
- 重大项目（≥ 100 万设备）须有实验室建设与设备管理处人员列席
- 重大项目须有财务部人员列席

### D：修改后通过（整改）
- 项目负责人按意见修改申报书
- 信办管理员审核整改（不符合退回继续整改）
- 通过后进入拟建清单

### E：论证不通过
- 第 1 次不通过 → 允许申请二次论证
- 第 2 次仍不通过 → 系统锁定 1 年，期间不可申请（1 年后自动解锁），详见 [[项目锁定与解锁规则]]

## 特殊立项通道

| 情形 | 处理 |
| --- | --- |
| 预算 < 5 万 | 信办管理员审批后直接立项，无需论证 |
| 上级要求 / 突发状况 / 学校决策会议 | 信办领导 / 领导小组直接下达立项通知书 |

## 核心状态

```
申报书填报中 → 申报材料审核中 → 专家论证中 → 论证结论
  → 拟建项目清单 → 已立项
```

## 业务规则（BR-10 ~ BR-15）

| 编号 | 规则 | 来源 |

## 核心功能

### 申报书（第十四条）
建设方案需包含：建设目标、建设内容、业务需求、技术方案、采购清单及预算（支持逐行添加并自动汇总）、实施人员、实施计划（甘特图组件）、采购需求调查。

### 主要数据表
- `project_proposal`：项目申报书
- `supplier_survey`：供应商调研记录
- `expert_pool`：专家库
- `argumentation_meeting`：论证会议
- `expert_review`：专家评审意见
- `approval_notice`：立项通知书（含采购截止日期、合同截止日期字段）
