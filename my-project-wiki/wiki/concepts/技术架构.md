# 技术架构

[[全生命周期管理系统]] 推荐技术栈：

| 层级 | 推荐方案 |
|------|---------|
| 前端 | Vue 3 + Element Plus / Ant Design Vue |
| 后端 | Spring Boot + MyBatis Plus / Java |
| 数据库 | MySQL 8.0 + Redis 缓存 |
| 工作流引擎 | Flowable / Activiti（支撑审批流、论证流、验收流） |
| 文件存储 | MinIO（校内部署） |
| 消息队列 | RabbitMQ（异步通知、定时任务） |
| 搜索引擎 | Elasticsearch（全局搜索、文档检索） |
| 部署 | Docker + K8s（校内私有云） |

## 关键设计点

- 工作流引擎（Flowable/Activiti）是核心组件，驱动审批流、论证流、验收流等所有流程节点
- 部署在校内私有云，数据不出校
- MinIO 负责所有项目文档的存储和归档
