# 项目招采模块

[[全生命周期管理系统]] 第三步。权威版本：[[业务流程说明书V1.1]]（BPD-2026-003）。

## 模块概述

立项通知书下达后，项目负责人编制采购文件并提交信办技术审核；通过后按项目级别执行对应采购方式确定承建方；合同拟定经审核后由合同管理员签订备案，触发 [[项目实施模块]]。

## 主流程（7 步）

1. 项目负责人根据《立项通知书》启动采购文件编制 → 状态「采购文件编制中」
2. 提交采购文件至信息办技术审核
3. 信办管理员技术审核 → 状态「技术审核中」（不通过退回 1）
4. **子流程 F**：按项目级别确定采购方式 → 状态「采购执行中」 → 确定承建方
5. 项目负责人与承建方拟定合同 → 状态「合同拟定中」
6. 信办管理员合同审核 → 状态「合同审核中」（不通过退回 5）
7. 合同管理员签订并备案归档 → 状态「合同签订」 → 触发 [[项目实施模块]]

## 子流程 F：采购执行方式

| 级别 | 采购方式 | 执行主体 |
| --- | --- | --- |
| 重大（> 200 万） | 政府采购公开招标 | 采购中心 |
| 中型（100 ~ 200 万） | 竞争性磋商 / 谈判 / 单一来源 / 合作创新 | 采购中心 |
| 小型（20 ~ 100 万） | 非政府采购挂网（询比 / 磋商 / 谈判 / 直接采购） | 采购中心 |
| 微型（< 20 万） | 信办审批后自行组织采购 | 信办管理员 + 二级单位 |

## 核心状态

```
采购文件编制中 → 技术审核中 → 采购执行中 → 合同拟定中 → 合同审核中 → 合同签订
```

## 业务规则（BR-16 ~ BR-20）

| 编号 | 规则 | 来源 |
| --- | --- | --- |
| BR-16 | 技术审核须覆盖技术规范一致性、接口标准、安全防护、数据治理 | 260409 会议 |
| BR-17 | 合同建设周期原则上 ≤ 2 年 | 260409 会议 |

## 自动监控规则

| 规则 | 触发 | 动作 |
| --- | --- | --- |
| 立项失效（采购） | 已立项超 6 个月未启动采购 | 标记「失效·需重新论证」，返回 [[立项论证模块]] |
| 立项失效（合同） | 已立项超 1 年未签订合同 | 标记「失效·需重新论证」，返回 [[立项论证模块]] |
| 合同周期预警 | 合同建设周期 > 2 年 | 系统自动预警 |

## 信息办技术审核重点（第二十五条）

- 技术规范是否与建设方案一致
- 接口标准是否符合学校统一规范
- 安全防护要求是否充分
- 数据治理和对接共享需求是否明确

## 合同关键条款（第二十六条）

- 建设周期：原则上 ≤ 2 年（系统自动监控预警）
- 数据治理集成与互联共享要求
- 付款方式：与项目进度挂钩
- 维保年限

完整条款详见 [[合同关键条款]]。

## 主要数据表

- `procurement_document`：采购文件
- `procurement_process`：采购过程（状态跟踪）
- `project_contract`：合同（含 `build_end_date ≤ 签约后2年` 约束）
