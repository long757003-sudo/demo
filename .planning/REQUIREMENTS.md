# Requirements: 西南大学信息化项目全生命周期管理系统 Demo

**Defined:** 2026-04-12
**Core Value:** 能完整走通一个项目从需求提出到运维交付的全流程演示

## v1 Demo Requirements

### 基础框架

- [x] **BASE-01**: 12 类角色切换，菜单随角色动态渲染
- [x] **BASE-02**: 四种页面模板（T1仪表盘/T2列表/T3表单/T4详情）基础结构
- [x] **BASE-03**: 工作台首页（T1），含待办、项目动态、通知区
- [x] **BASE-04**: 角色选择/登录页

### 需求征集模块（DEMAND）

- [ ] **DEM-01**: 信息办管理员发起需求征集，配置时间和通知范围，跳转通知页预填
- [ ] **DEM-02**: 单位系统管理员查看授权，指派本单位填报人
- [ ] **DEM-03**: 项目负责人填写需求申请表（T3），暂存/提交
- [ ] **DEM-04**: 单位系统管理员拖拽排序本单位需求，提交单位领导审批
- [ ] **DEM-05**: 单位领导审批需求排序（T4，含审批意见）
- [ ] **DEM-06**: 信息办管理员需求遴选（标记支持/不支持，含 BR-04 六类不予支持提示）
- [ ] **DEM-07**: 需求列表（T2），按状态和单位筛选

### 立项论证模块（PROJ）

- [ ] **PROJ-01**: 项目负责人填报申报书（T3，含建设目标/技术方案/预算明细/实施计划）
- [ ] **PROJ-02**: 信息办管理员立项审批（T4，含查看申报书、审批意见、通过/退回/提交领导小组 BR-09）
- [ ] **PROJ-03**: 信息办领导下达立项通知（T3，填写立项通知书，确认经费）
- [ ] **PROJ-04**: 申报书列表（T2，按项目分级标色）

### 专家管理&评审模块（EXPERT）

- [ ] **EXP-01**: 专家库列表（T2，按技术/业务/用户 × 校内/校外筛选，新增/编辑）
- [ ] **EXP-02**: 专家黑名单（T2，含列入原因/时间）
- [ ] **EXP-03**: 专家邀请记录（T2，每次评审的邀请状态）
- [ ] **EXP-04**: 发起评审（T3，选专家自动校验 BR-05，领导确认后发送邀请）
- [ ] **EXP-05**: 专家填写评审意见（T3，五维度打分 + 论证结论，BR-06 二次论证逻辑）
- [ ] **EXP-06**: 我的评审任务（T2，专家待办的论证/验收任务）
- [ ] **EXP-07**: 评审列表（T2，论证+验收统一列表，Tab 切换）

### 项目招采&合同模块（PROC）

- [ ] **PROC-01**: 采购管理（T4，调研填报 ≥3家 BR-17，接口调取招采系统数据 Mock）
- [ ] **PROC-02**: 合同台账（T2，含到期提醒）
- [ ] **PROC-03**: 经费管理（T2，合同进度款支付状态 + 年度预算使用总览，只读）

### 项目实施模块（IMPL）

- [ ] **IMPL-01**: 实施进展汇报（T3，按合同支付节点提交材料，BR-20 汇报频率提示）
- [ ] **IMPL-02**: 延期申请（T3，延期不超半年校验 BR-14）
- [ ] **IMPL-03**: 变更申请（T3，变更后触发专家论证 BR-22）
- [ ] **IMPL-04**: 项目终止申请（T3，5种终止情形单选 BR-24）
- [ ] **IMPL-05**: 项目详情（T4，生命周期进度条 + 审批流时间轴 + 操作记录 Tab）

### 项目验收&运维模块（OPS）

- [ ] **OPS-01**: 内部初验填报（T3，试运行 ≥1月校验 BR-15）
- [ ] **OPS-02**: 正式验收组织（T4，校外专家比例校验 BR-29，生成验收报告）
- [ ] **OPS-03**: 验收管理列表（T2）
- [ ] **OPS-04**: 运维记录（T2，巡检/备份/培训记录）
- [ ] **OPS-05**: 故障工单（T2，重大故障标红提醒 BR-38）
- [ ] **OPS-06**: 系统使用情况（T1，上线后运行数据仪表盘）

### 通知&日志&系统管理模块（SYS）

- [x] **SYS-01**: 通知模板结构（notification-template 已完成）
- [ ] **SYS-02**: 通知列表（T2，按类型和状态筛选）
- [ ] **SYS-03**: 新建/编辑通知（T3，通知类型/正文/发送对象/渠道/定时发送，支持跨模块预填）
- [ ] **SYS-04**: 通知发送详情（T4，收件人送达和已读状态，一键重发，导出凭证）
- [ ] **SYS-05**: 业务操作日志（T2，字段级 before/after 对比，只读）
- [ ] **SYS-06**: 系统操作日志（T2，权限变更等，只读）
- [ ] **SYS-07**: 用户与权限管理（T2）
- [ ] **SYS-08**: 流程配置（T2，Demo 中只读）

## Out of Scope

| Feature | Reason |
|---------|--------|
| 真实后端 API | 仅为演示原型，Mock 数据满足需求 |
| 移动端适配 | Demo 以桌面端演示为主 |
| 真实钉钉/OA/财务接口 | Demo 中模拟返回数据 |
| 生产级安全控制 | 角色切换仅为演示目的 |
| 等保测评实际流程 | Demo 中仅展示前置校验提示 |
