# 验收分级规则

## 细则版（按金额分级）

来源：[[验收阶段实施细则]] 第五、六条

| 金额 | 验收方式 | 专家要求 | 组织方 |
|------|---------|---------|--------|
| <20万 | 自行验收 | 无 | 建设单位自行组织，抄报归口单位 |
| ≥20万，<100万 | 竣工验收专家评审 | **3位校内专家** | 归口单位（信息办）组织 |
| ≥100万 | 竣工验收专家评审 | **5位校内专家** | 归口单位（信息办）组织 |

> **已确认**：与[[信息化项目管理办法]]存在矛盾，**以管理办法为准**。重大项目（>200万）校外专家不少于2人，≥500万校外专家须超过一半；验收细则的20万/100万校内专家门槛作为补充参考，不覆盖重大项目校外专家要求。

## 管理办法版（按项目级别）

来源：[[信息化项目管理办法]] 第三十八条

| 级别 | 校外专家要求 |
|------|------------|
| 重大（≥500万） | 校外专家须超过一半 |
| 重大（<500万，>200万） | 校外专家不少于2人 |
| 其他 | 按论证要求配置 |

## 竣工验收流程（≥20万）

```
建设单位提交竣工验收申请
    → 归口单位5个工作日内完成会前预审
    → 归口单位10个工作日内组织专家评审会议
    → 通过：出具验收报告，各方签字，正式投入使用
    → 不通过：整改（≤3个月）→ 再次申请
```
