# 产品详细设计方案摘要

## 文档概述

本文档是[[全生命周期管理系统]]的完整产品设计方案，以《西南大学信息化项目管理办法（试行）》为制度蓝本，将纸面制度转化为可执行的数字化工作流。

## 核心要点

### 1. 系统定位

面向[[信息办]]及各[[二级单位]]的信息化项目全生命周期管理平台，覆盖从需求征集到运维管理的完整闭环。

### 2. 角色体系

详见 [[角色体系]]。共 9 类角色：系统管理员、信息办专员、信息办领导、领导小组成员、领导小组办公室、二级单位经办人、二级单位负责人、采购专员、财务专员、专家。

### 3. 项目分级引擎

详见 [[项目分级规则]]。系统在项目创建时自动判定级别，驱动差异化流程。

### 4. 六大业务模块

| 模块 | 关键功能 | 对应 wiki 页面 |
|------|---------|--------------|
| 需求征集 | 征集通知、在线填报、自动初筛（6条规则）、人工复核 | [[需求征集模块]] |
| 立项论证 | 申报书填报、供应商调研、专家论证、立项审批、立项通知书 | [[立项论证模块]] |
| 项目招采 | 采购文件编制、技术审核、采购执行、合同管理 | [[项目招采模块]] |
| 项目实施 | 工作小组、实施计划（甘特图）、进度汇报、变更/延期/终止 | [[项目实施模块]] |
| 项目验收 | 内部初验、试运行（≥1月）、正式验收、项目移交 | [[项目验收模块]] |
| 项目运维 | 运维团队、故障工单（P0-P3）、巡检、备份、用户培训 | [[项目运维模块]] |

### 5. 公共能力层

- 消息通知中心（站内信 + 邮件 + 短信）
- 全局搜索 + 多角色看板（领导/信息办/二级单位）
- 文档管理与归档（全生命周期自动归档）
- 审计日志（所有关键操作可追溯）

### 6. 技术栈

详见 [[技术架构]]。

### 7. 实施路线

| 期次 | 周期 | 内容 |
|------|------|------|
| 第一期 | 2个月 | 需求征集 + 立项论证 |
| 第二期 | 2个月 | 招采 + 实施 |
| 第三期 | 2个月 | 验收 + 运维 + 看板报表 |
| 第四期 | 1个月 | 系统集成 + 性能优化 + 用户培训 |

## 重要业务规则（可追溯条款）

- 立项后**半年内未启动采购**或**一年内未签订合同** → 自动标记失效（第二十二条）
- 二次论证不通过 → **锁定一年**后方可重新提交（第十六条）
- 建设周期**原则上不超过2年**（第二十六条）
- 延期时间**一般不超过半年**；超半年自动标记负面清单（第三十一条）
- 试运行**不低于1个月**才可提请正式验收（第三十八条）
- 二次验收不通过 → **半年后**方可再次提出（第三十九条）
- 预算<5万 → 经信息办审批直接立项（第二十一条）
