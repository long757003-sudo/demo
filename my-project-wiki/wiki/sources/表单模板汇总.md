## 2. 信息化项目建设申报书

对应阶段：[[立项论证模块]]（第十四条）。由信息办制，2025年4月版。

### 表头信息
项目名称、项目用户单位、单位负责人、项目联系人、申报日期

### 基本情况表

| 字段 | 说明 |
|------|------|
| 项目类型 | 基础设施/硬件设备/信息系统/运维服务/数字资源（可多选）|
| 安装部署方式 | 学校数据中心 / 其他 |
| 服务对象 | 用户范围（教职员工/学生/其他）+ 访问范围（校园网/互联网/内网）|
| 项目预算（万元）| — |
| 资金来源 | 科研经费 / 单位自筹 / 校统筹经费 |
| 需对接的基础应用系统 | 统一身份认证 / 网上办事大厅 / **钉钉** / 其他 |
| 通知消息发送平台 | 短信 / **钉钉** / 一站式数智门户 / 其他 |
| 系统数据共享 | 默认共享所有数据，不能共享的需说明 |
| 系统拟申请使用的学校基础数据 | 人事/本科生/研究生/科研/教学/设备/财务/其他 |
| 硬件规格 | 高度(U)、电源功耗、网卡接口 |
| 服务器性能需求 | 数量、CPU、内存、算力、网络带宽 |
| 存储需求 | 应用数据(GB)、数据库数据(GB) |

### 安全信息表

| 字段 | 说明 |
|------|------|
| 是否提供互联网访问 | 是/否 |
| 是否采用独立用户注册认证 | 是/否（非学校统一身份认证）|
| 是否存储个人信息 | 是/否（含姓名/电话/身份证号等）|
| 处理的主要数据内容 | — |
| 数据重要程度 | 不可公开/审批后公开/可公开 |
| 数据数量级 | 百/千/万/十万/百万… |

### 信息化资源规划（信息系统类必填）

- 系统提供服务情况
- 信息化建设办公室网络安全检测建议（等保级别推荐）

### 正文章节

1. 项目基本情况
2. 项目建设的必要性及建设目标
3. 项目建设方案（建设内容）
4. 项目配置清单及采购资金预算
5. 项目实施计划
6. 项目建设单位及参与单位职能及意见
7. 专家组意见
8. 信息化建设办公室审批意见
9. 数智化建设领导小组审批意见（重大项目）

### 申报书填写说明中的论证专家要求

> **已确认，以管理办法为准**：申报书说明与[[信息化项目管理办法]]在100-200万区间校外专家要求上有出入，统一按管理办法执行（中型项目≥5人含校外专家）。

### 技术规范要求（应用系统开发）

详见 [[申报书技术规范]]。
